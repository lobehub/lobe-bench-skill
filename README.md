# LobeBench Skill

给 AI coding agent 用的技能：把模型评测做成一张 LobeBench 海报。

把仓库交给 Cursor / Claude Code / Codex / Copilot，说「做一张排行海报」即可。它会先让你选图、确认配置，再出图。
